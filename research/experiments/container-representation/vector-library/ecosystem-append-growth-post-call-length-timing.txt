Purpose: reproduce the registered contract-transport trial; retire this patch,
record and samples when superseding generic-contract transport evidence replaces
it. This is a post-lowering experiment on the nonconforming Z layout. No production
compiler change, new source rule, or paired performance conclusion.

and runtime objects. Z reproduction is recorded in empty-payload-anchor.patch and

entry len==cap relation, the allocation census and preparation-history patch.

Reproduction: copy the two frozen input whitefoot-{timed,account}.ll files into a
fresh directory, then git apply --directory=<directory> post-call-length.patch.
The exact input hashes below distinguish this diagnostic from a new emission.
Patch replay reproduced both outputs byte for byte. Each module has four added
instructions at each of exactly two grow_vector_append make_room call sites:

Removing exactly those eight instructions recovers each input byte for byte.
The ordinary make_room contract proves this relation on normal return only;
append subsequently changes length. This licenses neither invariant memory nor
reuse of a former payload pointer. Generic transport must newly resolve post-call
places and track relation support, including equal-length whole-owner replacement.

object bytes and original runtime link order are retained.
