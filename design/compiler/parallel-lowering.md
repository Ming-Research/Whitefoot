- Cell-range partition (C): rejected because every worker scans every iteration and evaluates its subscript, multiplying that work by worker count and restricting suitability to cheap indices and expensive contributions.
- Individual-iteration leaves with grain delegated to the runtime: rejected because they remove the loop shape needed for the body's own optimization.
- Denying every call-rooted match after the reference-only port: rejected because the existing if-condition compute call can still be the last member of a group that joins before dispatch. - Requiring an already captured scalar measure at the outer loop: rejected because it already works but the affected source observes its length only inside the helper, so it leaves the demonstrated whole-Box helper gap in place.
