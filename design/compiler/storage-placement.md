Decision: A consumed aggregate may reuse a same-typed whole result or the storage of one consuming field of a complete struct result once the callee has captured its inputs, with complete parent size, alignment and other live storage retaining the ordinary interference checks, because STOR-7 permits relocation without observable address identity and the retained priority helper exposes redundant whole-run transfers this reuse removes, instead of restricting reuse to whole results or promising a stable address in the language. WIN-3's whole-owner consume ends sibling uses; it does not remove the complete allocation's layout obligations.

Decision: Emit independent entry stack allocations for complete storage groups only when target qualification establishes positive sizes, one common natural alignment with no requested-alignment discrepancy, and no padding between groups or at the frame tail; retain the qualified struct otherwise, because every eligible ordering has the same checked complete extent and the retained-record experiment removes redundant snapshots when this representation is paired with descriptor-before-transfer window takes, instead of forcing unrelated eligible temporaries into one address-exposed object. The target plan owns the allocation recipe and still checks the complete frame before emission; storage interference, complete parent allocations, redirected destinations, probing and parallel-frame lifetime rules remain unchanged. Independent objects have allocation-relative offsets, not the fallback struct's physical field offsets.

Decision: A compiler-owned window take captures its old physical element address, updates the descriptor and then transfers the element as one complete lowering operation, because descriptor and element bytes are disjoint, no source observation intervenes, and moving the descriptor store before the transfer permits aggregate-copy forwarding, instead of preserving an element snapshot across a separate descriptor-update operation. Zero-sized elements transfer no bytes; the ordinary admitted row remains the sole source of access permission.

Decision: A definition reads a by-value aggregate parameter through the pointer its caller passed instead of copying it into its own slot at entry, when it has no result destination, does not wait, has no overlap group or split part, no native signature reaches it, and every value its slot holds originates from that parameter through block transfers alone, so an update, a reinitialization, an instruction result or a merge with another origin keeps the copy and nothing writes the caller's storage during the call, because Halo's Lua interpreter, whose `push_frame` copied an 80-byte `Frame` on every call, ran fib 3.8% faster on the 14900K with the rule widened to functions with branches while six other kernels stayed within noise ([measurement](https://github.com/Ming-Research/Halo-wf/actions/runs/37771086458)), which meets the reopening condition this node's earlier rejection named, instead of keeping the entry copy, which on firn alone measured no gain ([earlier measurement](../../research/investigations/in-place-parameters/DESIGN.md#results)).

Rejected:
- Treating one consumed child as permission to reuse an undersized or misaligned parent result allocation: rejected because the complete result still has to fit, including when the returned child is smaller than its parent.
