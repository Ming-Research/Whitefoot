Decision: A consumed aggregate may reuse a same-typed whole result or the storage of one consuming field of a complete struct result while the callee preserves each original input across possible aliased result writes, with complete parent size, alignment and other live storage retaining the ordinary interference checks, because STOR-7 permits relocation without observable address identity and the retained priority helper exposes redundant whole-run transfers this reuse removes, instead of restricting reuse to whole results or promising a stable address in the language. WIN-3's whole-owner consume ends sibling uses; it does not remove the complete allocation's layout obligations.

Decision: Emit independent entry stack allocations for complete positive-sized storage groups whose requested alignments equal their natural alignments, including mixed alignments, checking the sum over roots of (size + emitted alignment - 1) plus (maximum alignment - 1) with overflow checks against the target address-index domain before emission, because the [inplace-lets witnesses](../../research/investigations/in-place-parameters/DESIGN.md#ci-experiment-and-current-evidence) retain a dead snapshot in the mixed-alignment shared frame and remove it with separate allocations, and the owner selected separate allocations, instead of uniform-alignment-only independent allocas or alignment groups that still give unrelated roots shared provenance. Retain the exact struct fallback for zero-sized or over-aligned roots; split dispatch frames and their part signatures retain one object because the parts exchange its pointer and derive shared field addresses from it, parallel lane frames retain one object because the runtime receives its aggregate size and thunks and result accesses use its fields, and context argument frames retain one object because launch and thunk share its pointer and field offsets. The target plan owns each root's emitted alignment and the independent extent bound; struct offsets describe only the retained struct layout, and independent pointers are allocation-relative. Storage interference, complete parent allocations, redirected destinations, probing, parallel-frame lifetimes and OP-9 stored-type checks remain unchanged; the bound covers the planned roots, not storage allocated outside the plan or machine spills.

Decision: A compiler-owned window take captures its old physical element address, updates the descriptor and then transfers the element as one complete lowering operation, because descriptor and element bytes are disjoint, no source observation intervenes, and moving the descriptor store before the transfer permits aggregate-copy forwarding, instead of preserving an element snapshot across a separate descriptor-update operation. Zero-sized elements transfer no bytes; the ordinary admitted row remains the sole source of access permission.

Decision: A definition whose public result uses a destination also reads an immutable by-value aggregate parameter through the pointer its caller passed when the parameter and its unchanged block-transfer family occupy complete, unexposed allocations with no binding destination, field placement, placed child or returned slot and source stability is proved through each read-through use, with private capture on that path before its first potentially invalidating operation that precedes a use, because the [destination-result parameter evidence](../../research/investigations/in-place-parameters/DESIGN.md#destination-result-parameters) identifies Halo table_get's retained 16-byte key entry copy and a read-before-result-write opportunity, instead of excluding every definition whose public result uses a destination. Other ineligible consumers require private backing before the use. Decision: Remove internal block parameters and their matching incoming arguments before storage planning when no instruction operand, match scrutinee, return, drop or cleanup reads them directly or through forwarding, using the outlined-chunk capture pass's backward dependency walk and retaining ordinary instructions, source signatures and value identities, because a continuing match carries every binding and an unobserved duplicate destination prevents otherwise valid result-slot coalescing ([selection witness](../../research/investigations/in-place-parameters/DESIGN.md#unobserved-join-forwarding)), instead of weakening interference between live parameters or relying on the host optimizer to recover a producer's destination. Each needed value is visited once, so forwarding cycles without observations disappear and cycles reaching releases remain; waiting and overlap functions retain their instructions, schedules and existing storage restrictions.

Decision: Read eligible uses of a by-value Load snapshot through its captured source address when its complete, unexposed storage carries only that snapshot and checked effects and IR place facts prove the containing storage unchanged and valid through each read-through use; immediately before each other use materialize private backing on that path when the same facts establish stability up to that point, retaining the Load copy for the whole snapshot when any required interval cannot be proved, because the hot tag-reading path must not inherit a cold consumer's copy in the [Halo snapshot evidence and placement argument](../../research/investigations/in-place-parameters/DESIGN.md#read-through-snapshots), instead of requiring every use to read through or copying every by-value snapshot. Waiting functions, overlapping execution, exposed or mixed-origin storage and uses crossing split parts keep their existing restrictions; overlap exclusions follow the emitted world for callers and callees, so sequential clones retain ordinary sequential placement despite their overlap annotations. A destination-result callee does not by itself exclude a caller's read-through argument: it must preserve the original indirect input across the ABI's permitted result/input aliasing, using entry captures or the proposed incoming-parameter placement above. Checked own arguments whose representation contains only inline data cannot invalidate another source through that value; unknown or indirect representations retain conservative effects. The logical value remains the value at the read; this is storage placement and changes no language rule.

Rejected:
- Requiring writers to borrow-match instead: rejected because the by-value snapshot is a natural source form whose redundant transfer is a compiler gap, and changing the writer's spelling would hide that gap.
- Making indexed by-value reads borrows in the language: rejected because a snapshot must keep the value observed at the read even when its source later changes, whereas a borrow has different semantics.
- Treating one consumed child as permission to reuse an undersized or misaligned parent result allocation: rejected because the complete result still has to fit, including when the returned child is smaller than its parent.
- Uniform-alignment-only independent allocas: rejected because the inplace-lets mixed-alignment witness retains a dead snapshot that independent allocations let the optimizer remove in the uniform witness, and the checked per-root padding bound covers mixed alignments.
- Alignment groups: rejected because roots within each group would still share allocation provenance; the owner chose separate allocations to remove that coupling between unrelated roots.
