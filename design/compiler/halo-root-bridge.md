Decision: Halo retains each cached script's embedding root bridge in that script's constant-pool tail, invalidates all bridges on compile, pin and unpin, and sources rebuilds only from original constant prefixes and current pins with geometric reserve, because unchanged budget resumes must preserve every cached constant and host pin without repeated bridge allocation or copying, instead of rebuilding on every resume or introducing a separate collector root argument. This follows the owner's persistent-bridge direction and is provisional until the [cost-repair criteria](../../research/experiments/halo-bench/RESULTS.md#halo-cost-repair-criteria-recorded-before-measurement) and collector controls pass; reopen when cached constant editing or the collector interface changes.

Decision: Provisionally, the engine's script storage, original constant lengths, pins and bridge-validity flags are public readonly, because every root-set mutation must invalidate cached bridges and unrestricted external writes could bypass that guarantee, instead of permitting direct mutation with an unenforced invalidation convention. This is the recommendation awaiting the owner's Q1 ruling in the [invalidation assessment](../../research/experiments/halo-bench/RESULTS.md#halo-cost-repair-criteria-recorded-before-measurement); an explicit constant-editing API reopens it when a client needs one.
