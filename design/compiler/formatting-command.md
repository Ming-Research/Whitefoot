Decision: The command-line compiler offers one explicit formatting request, `--format` over the same sources `--check` takes or over a module graph, which rewrites in place every source whose bytes differ from its FORM-2 rendering and writes nothing when any source of the unit has no complete derivation, while checking and compilation keep rejecting non-canonical input unchanged, because canonical bytes are mechanically determined by the derivation the compiler already renders, so a writer who must reach them by hand loses compile rounds to layout alone (13 of 45 rejections in the first three rounds of the Whitefoot-kit writer trial were FORM rejections, most of them FORM-2), and an explicit request leaves acceptance exactly as strict as FORM-1 requires, instead of formatting during acceptance or leaving formatting to a script outside the compiler.

Decision: The rendering the formatting request writes and the rendering a FORM-2 rejection is judged against come from one library function that stops after grammar derivation and finalization, because two renderings could drift and a formatter that ran semantic checking would refuse to format a program whose only other faults are semantic ones, instead of a formatting path of its own or formatting only accepted programs.

Rejected:
- Formatting during `--check` or compilation: rejected because FORM-1 makes non-canonical input a hard error so that the bytes a writer keeps are the bytes the compiler judged, and silently accepting other bytes would make acceptance depend on a rewrite the writer never saw.
- A formatter script in Whitefoot-kit or in each downstream project: rejected because it would reimplement the FORM-2 rendering outside the compiler and drift from it, and Firn already had to build such a one-off tool against the compiler library.
- Writing the canonical bytes to standard output instead of in place: rejected because a module program has many sources and the writer's next step is always to keep the canonical bytes, so in-place rewriting with all-or-nothing writes serves the one use without a multi-file output format.
