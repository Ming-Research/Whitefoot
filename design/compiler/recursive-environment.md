Decision: In each strongly connected component of the call graph among definitions that have a checked source signature and neither wait, are synthesized, hand calls out, carry a recursion budget nor contain a dispatch loop, a read-only `&T` or `&[T]` parameter that every member has and that every call inside the component passes on unchanged, as the caller's own parameter directly or through block parameters that receive only it, travels in one record: each member's body is an internal `wf__env_<name>` form that takes one `noalias readonly` pointer to that record in place of those parameters and loads each once at entry, calls inside the component pass the caller's own pointer, and the member's public symbol keeps its ordinary signature and facts and becomes the entry from outside, which stores those parameters into a record in its own frame and calls the internal form, because every definition C or another fragment can name keeps the one callable ABI and the specification is unchanged, while a chain such as Snowghost's selector matcher, whose step passes 9 argument words and test 8 against x86-64's 6 integer argument registers, spends its per-call overhead on stack-passed arguments, argument preparation and spills around inner calls ([witness](../../research/investigations/recursive-shared-env/README.md)), instead of a source-level reference record or a different calling convention.

Decision: A component uses the record only when its slots replace at least two argument words and some member passes more integer-class argument words than the selected target's argument registers hold (six on x86-64 System V, four on x86-64 Windows, eight on AArch64), because below that budget every argument already travels in a register and the record could only add loads, provisionally until the [measurement](../../research/investigations/recursive-shared-env/README.md#comparison) decides, instead of packing every qualifying group or every borrowed parameter.

Decision: An internal entry is named `wf__<form>_<name>` by its form, which says which parameters a record carries and which calling convention it uses, and a call site chooses it in one place by the relation between caller and callee, naming the public symbol otherwise, because the record form and the split-part calling-convention entry are the same mechanism, a definition the compiler alone calls in a form no other definition sees, instead of a separate naming and selection path per form.

Rejected:
- A calling convention alone, `x86_regcallcc` or `preserve_nonecc`: rejected because regcall exists only on x86 and would need adapters for every linked C body sharing the callable ABI, while preserve_none clobbers the callee-saved registers the matcher keeps its state in and requires LLVM 19.
- A source-level record of references the writer passes: rejected because the owner chose the compiler route, which changes no accepted program; the language form stays a backlog candidate.
- Putting every borrowed parameter in the record whatever its words: rejected because a group whose arguments already fit the registers pays a load per slot for nothing.
- Admitting parameters written through: rejected because a pointer loaded from the record cannot carry the `noalias` that separates those writes from every other access, while a written parameter that stays an argument keeps it.
- A parameter some recursive edge passes as a different borrow, such as a narrowed range: rejected because one record slot holds one value for the whole activation chain.
- Every outside caller building the record at its own call site: rejected because the public symbol must build it anyway for C and other fragments, and the host inlines that small entry into the callers it sees, which gives them the same code without a second call-site path.
