Node: compiler

Decision: Runtime cache hashing uses a maintained SHA-256 implementation through its safe Rust API, with locked dependencies provisioned before offline checks and the small constant-evaluation implementation retained for specification identity, because the [module-product cost attribution and paired native comparison](../../research/experiments/modular-build-cost/RESULTS.md#current-main-audit) identify repeated scalar hashing of large retained records as material work and measure lower entry-edit compilation time with identical digest bytes, instead of maintaining platform-specific hash intrinsics in the compiler or weakening complete-key and checksum validation. The comparison gives main the same runtime optimization; the general gain alone does not establish the module-product cost target. The compiler crate continues to forbid unsafe code; hardware and software implementations must produce the same digest.
