Node: language/surface-form/text-literals

Decision: A character literal `'C'_TYPE`, with the mandatory suffix `u8` or `u32`, is an integer literal of TYPE denoting the scalar value of its one text item and is legal wherever an integer literal of TYPE is, a `u8` character holding only values up to 0x7F, because text-heavy programs such as the Snowghost renderer wrote every character test as a bare number and a character is a distinct construct from a number (`language/surface-form`), while a `u8` above 0x7F would read as one byte of a UTF-8 encoding rather than a character, instead of forcing the character spelling on printable byte values or naming characters only through standard-library constants.

Decision: Each Unicode scalar value has exactly one spelling inside a quote: the raw byte for printable ASCII other than `\` and the delimiting quote, `\\`, the quote escaped and `\n` for their three values, and `\u{H}` in lowercase hexadecimal without leading zeros for every other value, each quoted form escaping only its own quote and the source staying ASCII, because one spelling per value is what the surface-form principle asks of a literal's interior and a second escape family would give one value two spellings, instead of conventional escape sets with `\t`, `\x` or uppercase and zero-padded hexadecimal.

Decision: A STRING is also the `cvalue` of an `Array<u8, N>` constant, denoting the UTF-8 encoding of its scalar values, with N required to equal that byte length and a mismatch refused with a repair that states the length, and it is never an expression, because a message is static data that the constant array already stores and a length the checker states replaces the hand count Snowghost got wrong, while every type stays written in full, instead of a string expression, a string type, or an array length inferred from the text.

Decision: The shape of a text item, which escapes exist and that hexadecimal digits are lowercase, is decided when a token is classified, while whether an item is its value's one spelling, whether it denotes a scalar value and whether a `u8` holds it are decided at check time with a repair, a `doc` STRING included, because the float literal already splits its grammar from its canonical-spelling judgment this way and only the value judgments have a spelling to repair to, instead of rejecting every noncanonical item while forming tokens, where no repair is given.

Rejected:
- Forcing the character spelling for printable ASCII values, so that `97_u8` is illegal where `'a'_u8` can be written: rejected because arithmetic on byte values would then be written as text and numeric code would read oddly, as the owner ruled (decision card #21).
- Standard-library named constants for characters as the only relief: rejected because such constants name characters but give no way to write a message, as the owner ruled (decision card #21).
- Inferring an array length from its STRING: rejected because every type is written in full, and a declared length the checker checks states the storage at the declaration while the repair supplies the count.
