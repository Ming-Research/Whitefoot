Decision: Retained module products keep a local identity table and are imported into the composition's existing inventories through resolution-minted declaration and occurrence keys and structurally keyed instances, with source-check inputs distinct from target/layout/permission inputs and current composition judgments retained, because the [product import assessment](../../research/investigations/modular-compilation/DESIGN.md#retained-product-import) identifies one existing checked-model consumer path that can reuse bodies and lowering without propagating compound module-local identities through every proof and backend consumer, instead of sharing dense ordinals across checks or replacing those consumers with a second view over several inventories. Import and retention costs remain subject to the recorded qualification; identity equality alone grants no judgment reuse.

Decision: Group structural body records under one module source-input container, because the [qualification and work-reduction assessment](../../research/investigations/modular-compilation/DESIGN.md#retained-product-import) identifies repeated validation and copying of identical module inputs in per-function storage while the bodies share that invalidation boundary, instead of duplicating full module source inputs in every body record. Retain per-function structural keys and current composition judgments; qualification must establish that the grouped import costs less than the work it saves.

Qualification result: the grouped candidate preserves cached/fresh acceptance, diagnostics, LLVM and runtime equality and removes unchanged body/lowering walks, but the seven-pair real-consumer measurement remains slower and uses more compiler memory than the merged baseline. A focused source-input mutant and byte-framing mutants fail their regressions; the private-layout regression compares cached and fresh parallel fragments, while a physical-key mutant did not discriminate that source edit because the layout edit already invalidated the source product. The grouping therefore remains a proposal for the owner to accept, reject or reopen with a different representation; no performance improvement is claimed.

Rejected:
- Treating a retained body or a module's source verdict as a complete composition or target verdict: rejected because current call components, proof availability, physical layouts, target inputs and parallel permissions can change without the module's source judgment changing.
