Decision: The ordinary entailment walk associates each live local Result or Option whose success payload supplies contract data with an isolated conditional fact state over a private payload root, one root term for each integer value or measure the payload type supplies, which success delivery substitutes by the receiving binding's corresponding places, using the same difference-bound closure, support kills and joins as ordinary numeric facts, because one finite context per value preserves the verified call's authority and composes with existing control flow without a second solver or a product of independent guards, instead of delayed contract re-instantiation against mutable arguments or a source-shaped publication token. Decision: A Result with an integer success payload receives its conditional state at every value, as before, while any other admitted Result or Option receives one only where evidence first arises, at a success or failure construction whose payload has terms or at a routed call, and a join reads a missing state as the empty one, because the specification gives an unknown outcome an empty context, so both representations prove the same goals, and the values that never carry evidence, most Option and struct-payload values, then add no closure or join work, which keeps the check time of programs that route no such payload unchanged, instead of a state for every admitted value, which adds that work to every program holding an Option.

Decision: Measure and integer-field value placement follows owned fields, payloads and Box content structurally, stops structural descent at a repeated nominal, and supplements recursive operands with exact source paths from the existing term inventory after checking each path against the operand type, carrying a field's value only when its source place is already an interned term, because that finite inventory contains the earlier numeric evidence a placement can carry while unmentioned descendants need only their standing type facts, instead of infinitely unfolding recursive types, losing known deeper facts at the cycle boundary, imposing a path-depth limit, or minting a value datum for every integer field of every placed aggregate. This replaces the node's decision beginning "Measure placement follows owned fields", extending it to the integer-field values that specification v0.80's placements carry.

Rejected:
- A conditional state for every admitted Result and Option value: rejected because most such values carry no evidence, and their states would add closure and join work to every program holding one while proving nothing an absent state does not.
- A value datum for every integer field at every placement: rejected because a field that is no term has only its type's standing bounds, which hold at the destination without transport, so the datums would cost time and prove nothing.
