Node: compiler/terminal-owned-consumption

Decision: Provisionally lower the complete checked terminal take-back/exchange/back-drain permutation as one forward owned traversal only when a closed typed region and the accepted enclosing effect boundary exclude observation of its intermediate backing, keeping ordinary lowering for every unmatched body, because the permutation preserves callback, release and divergence order for arbitrary linear elements and the [bounded same-source diagnostic](../../research/investigations/containers-and-resources/X1-LIBRARY.md#checked-terminal-consumption-lowering-candidate) supplies grounds to implement and validate this optimization, instead of retaining avoidable element relocation in every admitted instance or changing the source storage API. This proposal selects implementation and validation of the conservative domain, not a general native-performance guarantee; acceptance, proofs, the ordinary callback ABI and target qualification remain unchanged.

Decision: Recognize the closed region while checked binding, operation, call and incoming-reference identities remain available, then retain each consumer as an ordinary typed-IR call and publish length through a private final-boundary operation only on the nonempty path, because dependencies, ownership transport and scheduling must continue to see the real calls and the LLVM emission model only prints target structure, instead of recognizing library names in emitted text, hiding a loop and its callbacks inside an opaque backend operation, or asserting additional alias facts.

Rejected:
- Replacing a local take/exchange pair without its complete continuation: rejected because a later backing read or partial return can observe the displaced rear owner and intermediate length.
- Selecting the optimization by collection name, callback name, element width or benchmark identity: rejected because those properties neither establish the permutation nor exclude surviving observers.
- Publishing the retained length on the empty path: rejected because the original empty traversal changes no state and the store adds unnecessary work. The diagnostic containing that store regressed its wide overhead controls, but the store's isolated time cost remains unmeasured.
