# Multi-result list

How a function returns more than one value.

### decision functions-may-return-a-result-list
A function may declare an ordered list of two or more results, bound only by a destructuring `let` or a `set` target list and never used as a value.
- rejected: an agent proposed requiring a declared struct for every return of several values; the owner rejected it, because a carrier struct for every combination of returned values is a cost, not a gap in what can be expressed.
