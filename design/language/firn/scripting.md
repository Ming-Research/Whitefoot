Decision: A script attempt executes synchronously in one atomic statement holding the whole keys map and metadata, abandoning a budget-exhausted attempt before its first write and retrying from the start with doubled budget, while an attempt that has written runs to completion, because this gives Redis-compatible atomic visibility with no rollback and permits yielding a read-only attempt ([selected direction C](../../../research/investigations/halo/DESIGN.md#selected-direction-owner-2026-10-04)), instead of releasing the hold around individual script commands or preserving an already-written checkpoint between statements.

Decision: Firn shares idle Halo engines and the SHA1-to-source registry in one engine pool; take and return each use a short statement outside the script's map hold, including error and abandoned attempts, and SCRIPT FLUSH advances a generation that invalidates an engine's compiled cache before use, because engine ownership and script identity span connections while pool access must not nest inside the keyspace hold, instead of one mutable interpreter shared for the duration of every script or connection-private registries.

Decision: Firn exchanges command results as RESP bytes and converts them to Lua by Redis 7.0.15's redisProtocolToLuaType rules, converting script results by luaReplyToRedisReply and freezing command time at script start, because scripts and ordinary commands need the same reply boundary and Redis's expiry observations, instead of Lua-specific command return values or refreshing time during a script.

Decision: The initial scripting slice confines redis.call and redis.pcall lookup, arity and refusal replies to one interim script_command adapter to be replaced by firn's shared registry, permanently refuses noscript commands with Redis's error and temporarily refuses the other commands as not yet supported in firn scripts, because the statement-callable bodies are supplied by the parallel firn command work and no command in this slice can write, instead of duplicating ordinary command semantics in the script host or appending scripts to the AOF before command writes exist.

Decision: Firn retains each successfully compiled EVAL or LOAD script until SCRIPT FLUSH, with no script-count cap or eviction, because Redis 7.0.15 retains those sources in luaCreateFunction until scriptingReset, instead of importing newer Redis script eviction behavior. SYNC and ASYNC both invalidate the registry before OK; firn performs source reclamation synchronously for either option because the visible cache result is identical, instead of adding a background reclamation path to this slice. Source/hash payload accounting excludes allocator overhead and engine heaps rather than presenting it as Redis's allocator-specific evalScriptsMemory total.
