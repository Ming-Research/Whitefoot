Decision: Reject an if-statement or value-if condition when every fact the branch it would select establishes at entry is already derivable by the fixed automatic disposition in its complete noncontradictory entering state, with a repair removing the test and the dead branch, because Q145 A selects executable source containing only tests its proofs still require and deleting such a test can then never break a later proof, instead of accepting redundant branches, issuing an implementation-dependent warning, or deciding by one origin while the deletion loses another, as the [origin-publication witness](../../../research/investigations/redundant-tests/DESIGN.md#deletion-repair-exposes-an-origin-publication-gap-q151) shows.

Decision: Judge a generic body's condition redundancy once under its own symbolic parameters and written bounds, because a branch required by some substitutions must remain writable when another substitution decides it, instead of reapplying this source judgment at each concrete instance or excluding generic bodies altogether.

Decision: Admit a condition under this rule when its entering state is contradictory, because explosion proves both signs and identifies no reachable branch to retain, instead of treating a contradiction as one decided Boolean value or adding a new unreachable-state rejection to the structural reachability rule.
