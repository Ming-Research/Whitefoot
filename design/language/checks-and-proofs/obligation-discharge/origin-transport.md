Decision: A goal disposition identifies typed value trees whose complete currently valid ordinary-let origin expansions agree, using a finite query view that shares signed proofs and equalities of represented integer values but publishes no new flow fact, because the [unguarded parity and later-known Boolean witnesses](../../../../research/investigations/origin-transport/DESIGN.md#question-and-prior-criterion) require proof in both directions and after the binding, instead of expanding only the submitted goal, publishing only facts known at the let, or retaining a runtime guard to supply another spelling of a proved proposition.

Decision: Origin transport uses the existing live definition links, ordinary kills and intersection at joins, with shared expansion identities and one term view per existing Boolean tree, because a computed binding may outlive the storage value it read and independent substitution choices would multiply trees, instead of retaining a killed equivalence or enumerating partial expansions.
