Decision: A join carries an enclosing loop header's written relation to the joined values when every non-contradictory input proves it over its own values, and the next header's batch is proved on each incoming edge separately, because a guarded update, a conditional length-preserving call and correlated updates each lose a written relation when the join intersects differing images, as the [witnesses](../../../research/investigations/join-relations/DESIGN.md#evidence-and-the-four-witnesses) show, instead of proving only at the back edge, widening each scalar independently, or carrying inferred relations.

Decision: Consecutive merges with no real event between them form one frontier, joined once with one transport batch at the next real statement, with compiler-derived releases and lexical scope kills applied separately to each input in source order and a required source judgment still ending the frontier, because publishing at every intermediate merge lets an inner result prove more at an outer join, so nesting the same branch set would change acceptance, as the [counterexample](../../../research/investigations/join-relations/DESIGN.md#canonical-proof-boundaries) shows, instead of publishing at each merge or saturating the set of written relations.

Decision: At a counted loop's next header, a measure whose index contains the counted binder is a separate target-instance term, identified by the place's proof path as ordinary terms are, so an exact reference alias and its referent share it, carrying only its type's standing relations, because the next slot can differ from the current one and reusing the current slot's term can prove a false bound, as the [indexed model](../../../research/investigations/join-relations/DESIGN.md#indexed-next-header-model-criterion) shows, instead of identifying the two by their source spelling.
