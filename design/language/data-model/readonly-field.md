Decision: A struct field may carry the modifier `readonly`, whether the prelude or a source module declares it, and the modifier states that only the declaring module writes the field rather than that its value never changes: outside the declaring module a path that ends at or passes through a readonly field is never the target of a `set`, never the argument at a reference parameter whose callee row writes that parameter and never a construction argument, while inside that module it is an ordinary field; the prelude is the declaring module of the storage shapes' length, capacity and head, so only prelude operations change them; a whole-value assignment still replaces the field together with its owner, a declared row may name it in `writes` because a row reports every change its callees make, and a source field carries `readonly` only when it is public, because the members the compiler maintains should be ordinary fields of ordinary declarations, and a writer with the same need, a member every holder may read that only the type's own operations change, must be able to update that member from those operations, instead of compiler-maintained members reachable by no declaration form a writer could use, or a readonly field that no source code may assign.

Rejected:
- A different word for a field that is not assignable, chosen so that the spelling could not be read as a promise that the value never changes: rejected because `readonly` is the word most readers already arrive with, and a read-only member whose value does change under the owning type's own operations is the familiar meaning of that word rather than a surprise it creates.
- Replaced decision that a readonly field is never assignable anywhere in the program: rejected because a source type's own operations could then never update a published member in place, so the purpose that decision states was reachable only by the prelude.
- Readonly on a private field: rejected because a private field is already unreachable from other modules, so the modifier would restrict nothing.
