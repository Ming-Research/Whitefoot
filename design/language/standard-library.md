Decision: The prelude keeps only the declarations a language rule names, namely Bool, Option, Result, Overflow, DivError and NarrowError, the Int and Float bounds, the storage shapes, the Box cell and their construction and window operations with swap and free_empty, visible in every module, while every host declaration, ExitStatus and Inputs included, belongs to a standard library module, because conditions, propagation, the checked operations, layouts and the storage operations are the language's own meaning that no module can do without, whereas no rule names a host declaration and injecting all of them into every check costs 36 to 62 percent of a check's instructions ([library-modules E1](../../research/investigations/library-modules/DESIGN.md#measurement-e1-what-the-host-rows-cost-every-check)), instead of a prelude holding the host interface, keeping the invocation types ExitStatus and Inputs in the prelude, or moving the storage shapes into a library module whose layout and operations the checker must know anyway.

Decision: A module check reads a standard library module's interface, and a composition selects the module, only when a graph row lists it or a source bundle names it, because the single dependency authority already decides which interfaces a verdict depends on and a check that names no host declaration then pays nothing for the host interface, instead of standard library modules joining every check and closure.

Decision: The specification states the exact interface text of the standard library modules whose definitions the build supplies, and the standard library's Whitefoot modules are checked library code outside it, because the safety guarantees depend on supplied definitions honoring their boundaries and the constitution requires the specification to state the external conditions its guarantees depend on, while a Whitefoot body is checked like any program's, instead of moving the host interface out of the specification with the rest of the library or specifying every library module.

Decision: The standard library's source lives in the repository's lib/std directory as one package with its own modules.wfg, and the compiler carries those records' bytes from its own build, because a library that ships with the compiler then always matches it, needs no installed location, search path or version check, and enters every cache key through the compiler's identity and its records' bytes, while the owner already selected root lib/ as the home of reusable Whitefoot source, instead of locating the library on disk beside the executable, through an environment variable or through a command-line root, each of which adds a way for the library and the compiler to disagree.

Decision: The container libraries become the standard library's first Whitefoot modules, under std::collections, with their existing callers and allocation ledgers as the move's regression suite, because a module program can reach no source outside its package root and binding other packages stays deferred, so the standard library is the only way programs can share them without copying, and they are the measured reusable code whose boundaries the owner already adopted, instead of keeping library source as text a caller concatenates before its own or deferring Whitefoot library modules until more helpers exist.

Rejected:
- Moving the storage shapes, Box or their operations into a library module: rejected because their layout, measures and allocation facts are language meaning the checker needs in every module, so a module form would add a declaration path without removing any compiler knowledge.
- Keeping ExitStatus and exit_status in the prelude to spare the 1,159 conformance sources that name them: rejected because no language rule names them, the runner that interprets a returned value can recognize the standard library identity as easily as a spelling, and migration cost is not a ground before real project adoption.
- A command-line or environment root for the standard library: rejected because it lets a program be checked against a library other than the one its compiler ships, a failure the embedded library cannot have, and no current experiment needs to substitute the library.
